## Generating Charts

To regenerate charts from benchmark data, use a tool like gnuplot or matplotlib:

```python
import matplotlib.pyplot as plt
import numpy as np

sizes = ['64B', '256B', '1KB', '4KB']
tcp = [17897, 18376, 17738, 19864]
uds = [2459, 2375, 2600, 3498]
shm = [307, 366, 335, 550]

x = np.arange(len(sizes))
width = 0.25

fig, ax = plt.subplots()
ax.bar(x - width, tcp, width, label='TCP Loopback')
ax.bar(x, uds, width, label='Unix Socket')
ax.bar(x + width, shm, width, label='Shared Memory')

ax.set_ylabel('Latency (ns)')
ax.set_title('Roundtrip Latency by Transport')
ax.set_xticks(x)
ax.set_xticklabels(sizes)
ax.legend()
ax.set_yscale('log')

plt.savefig('latency_comparison.png')
```
